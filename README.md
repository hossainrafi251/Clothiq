# CLOTHIQ Vibe

Please use the attached logo image for the brand header and design the website according to its color theme.

Create a modern, luxury E-commerce web application for a men's fashion brand named "CLOTHIQ" with the slogan "OWN YOUR VIBE".

Design & Theme:

- Dark luxury theme directly inspired by the attached logo. Use charcoal/dark slate background (#1A1E24), vibrant teal gradients (#008B9B to #00E5FF), and elegant metallic gold accents (#D4AF37).

- Clean, premium typography and responsive layout using Tailwind CSS.

Header & Navbar:

- Place the attached "CLOTHIQ" logo prominently in the header.

- Navigation links: "Men's Clothing", "Accessories", "Watches", "Best Sellers", "New Arrivals".

- Search icon, wishlist, and interactive Shopping Cart drawer on the right.

Hero Section:

- Headline: "THE ESSENTIAL COLLECTION — ELEVATE YOUR VIBE".

- High-quality visual showcase of men's formal/casual outfits (pants, shirts, and watches).

- Strong Call-To-Action (CTA) button: "Explore Collection".

Category Section (Banners):

- Grid layout showcasing main categories:

  1. Men's Shirts & Pants

  2. Men's Watches

  3. Accessories (Wallets, Ties, Belts)

Product Grid (Shop Section):

- Clean 4-column product cards showcasing watches, shirts, and pants.

- Display Product Title, Price, Ratings, and "Shop Now" / "Add to Cart" button on each card.

Footer:

- Includes logo, quick links, contact info, privacy policy, and social media icons (Facebook, Instagram,  Whatsapp icon)
